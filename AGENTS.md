# Agent entry point

Read these files in order before working in this repository:

1. `.agents/supacharger/guidance.md` for instruction ownership and reference routing.
2. `.agents/project/AGENTS.md` for project-specific rules, if present.
3. `.agents/supacharger/core-development/AGENTS.md` for Core contributor rules, only if installed. An absent optional directory is normal; do not install it merely to orient yourself.

Use `docs/agents/agent-guidance.md` to find Supacharger development conventions and technical references. The repository-knowledge MCP exposes these same references; it is not a separate instruction source.

Existing `.agents/instructions/` and `.agents/skills/` remain in place. Read task instructions when relevant and a skill's `SKILL.md` when using that skill.

[Previous directives](.agents/legacy/original-agents.md) are an inactive historical archive. Do not apply them automatically or reinstate them without a human request.

This routing structure deliberately permits a blank project instruction file. The archived requirement to duplicate the translation policy in every AGENTS.md does not apply to this structure.
